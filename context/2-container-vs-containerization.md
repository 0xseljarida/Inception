## Containers and Containerization

**Containerization**  
↓  
The technique/process of creating isolated environments.

**Container**  
↓  
The resulting isolated environment/process. (PROCESS here means a PROGRAM in execution)

**Namespaces + cgroups**  
↓  
Linux kernel mechanisms used to implement it.

**Docker / LXC**  
↓  
Tools that create and manage containers.
